# 无声无息 · Once Again 官方网站

![Once Again 服务器标题](最新服务器title.png)

沉默不会结束，这一次我们再次出发。

这是无声无息 · Once Again Minecraft 服务器的官方网站源码。网站使用独立 HTML、共享 CSS 和原生 JavaScript，保留 Minecraft 像素风格、森林绿与纸张配色，以及深浅主题，没有构建步骤或前端运行依赖。

**服务器目前处于筹备阶段。地址、开放时间及官方社区入口以官网后续公布为准；页面中的玩法规划不代表已经上线。**

[访问官网](https://zxwusheng.github.io/) · [团队介绍](https://zxwusheng.github.io/jieshao.html) · [协作者招募](https://zxwusheng.github.io/ztdh.html) · [赞助支持](https://zxwusheng.github.io/scene1.html)

## 网站功能

- **首页与筹备动态**：介绍服务器世界观、玩法方向、动态与规划，展示加入入口的开放状态。
- **团队介绍**：查看成员职责和档案；这里是静态团队展示，不是实时在线人数或开发进度。
- **协作者招募**：展示模型与动画、Mod 开发、材质贴图、UI / 平面绘制、音乐制作和建筑设计六类岗位，提供报名步骤、作品建议及既有联系方式。
- **赞助支持**：说明服务器维护、玩法优化与内容筹备的用途，提供支付宝和微信收款码、放大预览及原图入口。赞助完全自愿。
- **桌面与移动体验**：统一导航和页脚，支持深浅主题保留、移动菜单、键盘操作、减少动态偏好及图片加载失败提示。

官网沿用原站关于原版生存、个人动态难度、安全区旅馆、怪物代币与角色成长的介绍；具体实现和开放情况以真实公告为准，不将筹备说明当作当前游戏承诺。

在仓库根目录启动 HTTP 服务，再打开 [本地首页](http://localhost:8000/)：

```powershell
py -m http.server 8000 --bind 127.0.0.1
```

如果环境没有 `py`，可使用 `python` 或本机 Python 可执行文件路径。通过 HTTP 检查页面跳转、地址参数、图片和主题保存。

当前 GitHub Pages 发布源为 `main` 分支的 `/ (root)` 目录，入口为 `index.html`。保留根目录的 `.nojekyll`，让 HTML、CSS、JavaScript 和图片直接作为静态文件发布。`sitemap.xml`、`robots.txt` 及各页 canonical/Open Graph 信息使用 `https://zxwusheng.github.io/`；站点域名变化时需要同步更新。更新后检查 Pages 部署任务是否成功，本地提交或推送成功不等于部署成功。

## 内容配置

在 `site-config.js` 中维护公开配置：

| 字段 | 用途 |
| --- | --- |
| `serverAddress` | 已确认的服务器地址；留空时显示筹备状态并禁用复制 |
| `communityUrl` | 官方社区入口 |
| `feedbackUrl` | 问题反馈入口 |
| `rulesUrl` | 服务器规则入口 |
| `updates` | 首页动态列表，按新到旧排列 |

未知地址及三个入口继续留空；入口仅接受 HTTP/HTTPS 地址。不要填写示例群号、未经确认的服务器状态或赞助权益。地址或入口开放后，还需要同步页面中的筹备状态说明。`updates: []` 保留首页已有内容；填写时采用以下结构，并将说明文字替换为真实信息：

```javascript
updates: [
  {
    id: 'update-id',
    title: '填写已确认的标题',
    date: '',
    category: '公告',
    status: '填写真实状态',
    body: '填写已确认的内容'
  }
]
```

`id` 使用小写字母开头的字母、数字及短横线；`title` 和 `body` 必填。日期使用 `YYYY-MM-DD`，未知时留空，页面显示“日期待补充”。条目按填写顺序显示，不会自动排序；标题和内容按普通文本呈现。

招募页已有 QQ / 微信信息位于 `ztdh.html` 的 `#apply` 联系卡片。经确认后维护时，同步修改显示文字与复制按钮的 `data-copy-text`，不新增未经核实的联系方式。岗位、报名模板及合作说明也在该页维护。

## 赞助图片

两张 PNG 由原页面 Base64 数据直接解码提取，保留原始 PNG 字节，没有裁切、缩放、重绘或重新编码。赞助页支持放大查看和打开原图，弹窗支持关闭按钮、遮罩、ESC 与键盘焦点返回。

| 文件 | 支付渠道 | 原始尺寸 |
| --- | --- | --- |
| `assets/payments/alipay.png` | 支付宝 | 1080 × 1680 |
| `assets/payments/wechat.png` | 微信支付 | 1263 × 1719 |

原始 SHA-256：

```text
支付宝：3f73ea9670837c05015b1511050aa2c39f2e6c1bdc1b33d3b806896930061554
微信：150fd17f9a7d83628d53f9bbaed95cf67f31f175fc4b096b13ef962f9e3e38f5
```

可在 PowerShell 中检查文件：

```powershell
Get-FileHash -LiteralPath assets/payments/alipay.png,assets/payments/wechat.png -Algorithm SHA256
```

严禁在视觉或性能优化中替换收款码、重绘二维码、改变收款信息或交换支付渠道。确需更换时，必须单独取得明确授权并审查收款信息，再同步图片、对应按钮、校验记录及 QA 基线。图片哈希一致仅证明原字节保留，扫码识别仍需在实际支付应用中人工验证。

## 检查与维护

通过本地 HTTP 服务检查四个主页面：

- 在 320、375、390、768、1024、1440px 宽度下检查排版、遮挡和横向滚动。
- 检查页面之间完整跳转、顶部及页脚导航、移动菜单和主题保存。
- 用鼠标和键盘验证成员切换、复制反馈、图片预览的打开/关闭、ESC、Tab 循环与焦点返回。
- 检查图片、二维码、浏览器控制台、资源请求失败及慢响应下的表现。
- 确认未知功能显示明确状态，不出现无响应按钮、占位链接或未经确认的数据。

未运行的测试不标为通过。浏览器检查、Lighthouse、真实移动设备及支付应用扫码属于不同层级，应分别记录。

## 常见问题

**服务器地址无法复制**：地址尚未确认时会禁用复制，等待正式公布即可。

**社区、反馈或规则入口没有开放**：对应配置仍为空，页面会显示状态提示；不要自行补入非官方地址。

**图片或收款码未显示**：检查网络和资源路径，刷新后重试；赞助页可使用原图链接查看，不要用其他二维码替代。

**修改后线上仍是旧页面**：先检查 Pages 部署任务，再强制刷新浏览器，核对当前页面与 `main` 中的文件。

**希望参与协作**：阅读[协作者招募页](https://zxwusheng.github.io/ztdh.html)，按页面流程整理方向、能力与可选作品，再通过该页公布的联系方式沟通。
